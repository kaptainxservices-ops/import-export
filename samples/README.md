# samples

Real client emails and attachments go here. **Everything in this folder except this
file is gitignored** — client data does not belong in a git repository.

What we need (checklist step 1), 30–50 messages:

- ordinary daily price lists
- at least one with an **Excel attachment**
- at least one **screenshot / photo of a list**
- at least one **reply chain** with quoted history
- **two consecutive daily lists from the same seller** — these prove the
  disappearance rule works
- the messiest ones you have; clean examples teach the parser nothing

Any format: `.eml`, `.msg`, exported PDFs, pasted text in `.txt`, images.
